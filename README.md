# UAV-Work
1. 设计背景与目标
本报告自拟设计一款用于室内及园区自主巡检的微型无人机。该无人机需要具备全自主导航、避障、实时图传以及远程安全接管的能力。基于此需求，对其硬件组成进行如下选型与架构设计。
2. 核心硬件组成与选型
本无人机采用“感知-决策-执行”的分层架构，主要由以下硬件模块组成：
a.决策与运算单元：选用高性能机载电脑（如 NVIDIA Orin NX）负责运行SLAM、路径规划等复杂算法；选用开源飞控（如微空NXT PX4）负责底层的姿态控制和电机输出。
b.感知传感器模块：搭载 Livox Mid360 激光雷达用于三维环境建图与避障；配备 RGB-90 前视相机与 RGB-120 下视相机用于视觉识别；搭载优象光流传感器用于室内无GPS环境下的精准定位。
c.动力与执行机构：采用 4个 F90 无刷电机（KV1300）提供动力，配合 GF 7037 三叶竞速桨叶产生升力；选用蓝鸟 50A 四合一电调进行电机驱动。
d.遥控与安全链路：配备 AT9S Pro 遥控器与 R12DSM 接收机，用于紧急情况下的飞手接管。
e.供电系统：搭载 21700-6s1p 锂电池，通过分电板为整机提供 24V 及 12V 电压。

a.感知层：激光雷达通过网线（Ethernet）与机载电脑通信；相机通过 USB 连接；光流传感器通过 UART/MAVLink 协议连接飞控。
b.控制层：机载电脑与飞控之间通过 UART/MAVLink 协议进行指令传输。
c.执行层：飞控通过 Dshot600 协议控制电调，电调输出 3相交流电驱动电机。
d.遥控链路：接收机通过 SBUS 协议与飞控通信，保障飞行安全。
4. 总结
本硬件方案通过合理选型和协议搭配，满足了自主巡检无人机对算力、感知精度和动力冗余的要求。
